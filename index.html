About This Game

Punjabi Toffee Crush is a free educational game made by Deepali Tokhi from Delhi for kids age 3-10. This game helps kids learn Gurmukhi letters ੳ ਅ ੲ, Akhar ਕ ਖ ਗ ਘ, Punjabi numbers ੧ ੨ ੩, and simple words like ਮਾਂ, ਪਾਣੀ, ਘਰ. No login, no data collection, 100% safe for kids. Play 10 mins daily to improve memory and Punjabi reading. This game is for Punjabi families in India, Canada, UK, USA, Australia.

How to Play

Click same toffees to match. Learn while playing. Parents can say letters loudly - ੳ, ਅ, ੲ, ਕ, ਖ, ਗ. Praise kids with ਸ਼ਾਬਾਸ਼!
